## Permasalahan dan Langkah-langkah dalam memuli Percobaan Kasus Bolean

# Menginstal Python
1. Pastikan python sudah terinstal di leptop kalian, jika belum python dapat di instal melalui website python atau kunjungi _python.org_
2. klik download lalu instal setelah itu masuk dan lakukan apa yg diinstruksikan oleh python sebelum dapat diakses.

jika python belum terinstal maka tidak bisa mengakses cmd. 

Error:
~~~bash
'python' is not recognized as an internal or external command
~~~

# Cara Membuka Dan Mengoperasikan Python Di cmd
1. setelah python terinstal kemudian kalian akan membuka cmd melalui _windows + r_ kemudian ketik cmd pada Pop-up.
2. setelah kalian masuk di cmd untuk memastikan python telah terinstal ketik _python --version_ jika sudah terinstal maka akan keluar nomor versi python yang kalian instal tadi.

# Memulai Percobaan Kasus Bolean
1. Untuk menulis code kalian akan membuka notepad terlebih dahulu dengan mengetik _notepad nama_file.py_
2. Setelah masuk kedalam notepad kalian bisa langsung mengimplementasikan Studi kasus yang akan kalian tulis.
3. Setelah selesai menulis code dan di save kemudian kalian dapat melihat hasil dari code kalian tersebut melalui cmd. Untuk melihat hasil kalian ketik _python nama_file.py_

Warning⚠
Harus teliti dalam memasukkan code, salah sedikit saja maka hasilnya akan Error
